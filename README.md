# 标准 AGENTS.md 模板

这是一份跨项目复用的编码 Agent 说明骨架。新项目复制根目录的 `AGENTS.md` 和 `AGENT.md`，只填写标记为「填写」的段落，不要让 AI 重新生成整份结构。

## 为什么是 AGENTS.md

行业与 Cursor 当前约定的文件名是 `AGENTS.md`（有 s）。Cursor、Codex 等会自动加载它。`AGENT.md` 是旧称，本模板里它只作为入口，指向 `AGENTS.md`，避免有人按习惯打开错文件。

官方说明：
- https://agents.md
- https://cursor.com/docs/rules

## 新项目怎么用

1. 把 `AGENTS.md` 和 `AGENT.md` 放到仓库根目录。
2. 只改「填写」小节：项目概述、仓库地图、命令、本项目改动规则、验证命令、提交约定。
3. 「固定规则」整节不要改、不要删标题、不要调换章节顺序。
4. 每个需求开一个新的 Agent 窗口；窗口开始后先读根目录 `AGENTS.md`（若在子目录工作，再读离文件最近的那份）。
5. 子项目需要不同约定时，在该目录再放一份 `AGENTS.md`，只写增量，不要复制根文件全文。更近的文件优先，用户在对话里的明确要求压过文档。

## 这份文件不能保证什么

它能减少「每个窗口各写一套规则」造成的漂移，并要求改完必须跑通验证命令。它不能代替测试、审查和你对需求的确认。

## 不要做的事

- 不要每开一个项目就让 AI 从零再写一份 AGENT 文档。
- 不要把 README（给人看的）和 AGENTS.md（给 Agent 看的）混成一篇。
- 不要在功能开发任务里顺手改这套骨架的章节结构。
