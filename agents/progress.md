# 当前任务进度

用途：在「每个需求新开一个 Agent 窗口」的工作方式下，交接当前真实进度。
何时阅读：每次开工必读；本次任务结束前必须更新自己负责的条目。

## 规则

- 只记录真实状态，不要把计划写成已完成。
- 不要删除或改写他人进行中的条目，只能更新自己负责的任务。
- 做完后把条目移到「最近完成」，并写清验证方式和残留问题。
- 「最近完成」只保留仍有参考价值的记录，不要写成完整史书。
- 本页不是需求池。尚未开始、也没有负责人的想法不要写进来。
