# 验证

用途：规定 Agent 在声称完成前必须实际执行的检查。
何时阅读：结束前必做。

## 规则

- 只写必须真正跑完的命令，按顺序排列。
- 没跑过的检查，不要写成已经通过。
- 命令本身的说明在 `commands.md`；本页写「完成前要跑哪些、通过标准是什么」。

## 填写

完成前必须执行：

1.
2.

完成标准：

- 上述命令退出码为 0，或失败原因已写明。
- 本次改动有对应测试，或写明为何不需要。
- 没有把密钥或本机路径写进仓库。
- `agents/progress.md` 已更新自己负责的任务。
- 若确认了新踩坑点，已追加到 `agents/pitfalls.md`。
