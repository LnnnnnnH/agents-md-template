# 安全与注意

用途：记录本仓库在密钥、权限、外发和不可逆操作上的风险。
何时阅读：涉及密钥、权限、生产数据、外发或破坏性操作时；拿不准时也读。

## 规则

- 没有额外项时写「本项目暂无额外项」。通用规则（不提交密钥、不改 `.env` 除非用户明确要求）已在 `AGENTS.md` 固定规则中。
- 写清「谁可以动、什么绝对不能做」，不要只写「注意安全」。
- 不要在本文件中写入真实密钥、账号口令或完整凭证。

- 不可逆操作（删除、重置、迁移、公开发布）限制：
- 其他本仓库特有风险：

没有以上各项时写：本项目暂无额外项。
